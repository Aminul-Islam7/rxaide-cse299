System Capabilities

Core Implementation

Technical breakdown of the five primary capabilities implemented within the system.

AI Prescription Scanning

3-pass image analysis: full scan → detailed extraction → cross-verification. Supports handwritten & printed Bangla/English prescriptions. Google Search grounding verifies medicine names against pharmaceutical databases.

Gemini 2.5 Flash · CameraX · 24K thinking tokens

Automatic Schedule Generation

Decodes Bangladesh-style dose notation (e.g., "1+0+1") into structured schedules. Calculates end dates from duration strings. Creates Medication + Schedule + WorkManager entries in a single transaction.

ChatViewModel · Room · WorkManager

Reliable Reminders

24-hour periodic WorkManager tasks with precise initial delays. Custom notification sounds via MediaPlayer. Action buttons (Taken/Missed) handled by BroadcastReceiver. Survives reboots via BootReminderReceiver.

WorkManager · NotificationCompat · BroadcastReceiver

Dose Adherence Tracking

DoseGenerationWorker back-fills missed dose records from startDate to today. Time-filtered analytics (Today/Week/Month/All). Per-medication adherence percentages with reactive Flow-based state updates.

AdherenceViewModel · DoseHistoryDao · StateFlow

Conversational AI Assistant

Context-aware chat using [CURRENT_MEDICATIONS] injection. Action block parsing: [SCHEDULE_UPDATE], [MEDICATION_UPDATE], [MEDICATION_DELETE] — AI responses trigger real database mutations. 20-message sliding context window.

GeminiService · ChatViewModel · Action Block Parser

Polished UI/UX

Material 3 with custom dark/light themes. Animated screen transitions with directional slide. Horizontal swipe between tabs. Pull-to-refresh. Zoomable prescription image previews in chat. Markdown-rendered AI responses.

Jetpack Compose · Material 3 · Compose Markdown

2. AI System Prompt — Bangladesh Dose Notation Decoder — The system prompt teaches Gemini how to interpret local prescription conventions.

ai/GeminiService.kt lines 66–77
Kotlin (String) 
━━━ DECODE BANGLADESH-STYLE DOSAGE NOTATION ━━━
These indicate doses per time of day as (Morning + Noon + Night):
• "1+1+1" → 1 in morning, 1 at noon, 1 at night → frequency = "Three times daily"
• "1+0+1" → 1 in morning, 1 at night            → frequency = "Twice daily"
• "0+0+1" → 1 at night only                     → frequency = "Once daily"
• "½+0+½" → half in morning, half at night       → frequency = "Twice daily"
• Bengali digits: ০=0, ১=1, ২=2, ৩=3, ৪=4, ৫=5, ৬=6, ৭=7, ৮=8, ৯=9

3. Multimodal Image Analysis — Sends the prescription photo to Gemini with a 24K thinking budget. The GoogleSearch tool is attached for medicine name verification via search grounding.

ai/GeminiService.kt sendImageMessage()
Kotlin 
suspend fun sendImageMessage(imageUri: String, chatHistory: List<ChatMessage>): String =
	withContext(Dispatchers.IO) {
		val imageBytes = loadImageBytes(Uri.parse(imageUri))
		val contents = buildChatContents(chatHistory, IMAGE_ANALYSIS_PROMPT, imageBytes)

		val config = GenerateContentConfig.builder()
			.systemInstruction(Content.fromParts(Part.fromText(SYSTEM_PROMPT)))
			.tools(googleSearchTool)          // Google Search grounding enabled
			.temperature(0.1f)
			.maxOutputTokens(4096)
			.thinkingConfig(
				ThinkingConfig.builder()
					.thinkingBudget(24576)      // 24K tokens for deep analysis
					.build()
			).build()

		client.models.generateContent("gemini-2.5-flash", contents, config)
			.text() ?: "Could not analyze this prescription."
	}

5. WorkManager Reminder Scheduling — Calculates the exact millisecond delay until the next occurrence of the scheduled time, then enqueues a 24-hour periodic worker.

notification/ReminderScheduler.kt
Kotlin 
fun scheduleReminder(context: Context, medication: Medication, schedule: Schedule) {
	val now = Calendar.getInstance()
	val target = Calendar.getInstance().apply {
		set(HOUR_OF_DAY, schedule.timeHour)
		set(MINUTE, schedule.timeMinute)
	}
	// If target already passed today, schedule for tomorrow
	if (target.before(now)) target.add(DAY_OF_YEAR, 1)

	val initialDelayMs = target.timeInMillis - now.timeInMillis

	val workRequest = PeriodicWorkRequestBuilder<ReminderWorker>(24, TimeUnit.HOURS)
		.setInitialDelay(initialDelayMs, TimeUnit.MILLISECONDS)
		.setInputData(data)    // med name, dosage, schedule ID, sound URI
		.addTag("med_reminder_${medication.id}_${schedule.id}")
		.build()

	WorkManager.getInstance(context)
		.enqueueUniquePeriodicWork(tag, REPLACE, workRequest)
}
